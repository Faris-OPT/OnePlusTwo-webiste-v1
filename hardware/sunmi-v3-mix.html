How does the Sunmi V3 Mix take payments?

It takes contactless payments with Tap to Pay via NFC, using the tablet itself as the card reader.

Can the Sunmi V3 Mix be used as a desktop till?

Yes. It works with the same optional cradle base as the P3 Mix.

Does the Sunmi V3 Mix work with OnePlusTwo?

Yes. We supply the Sunmi V3 Mix set up and ready to use with OnePlusTwo, and we make sure it works with the rest of your hardware from day one.
